# Site audit — 2026-09-01

## Scope reviewed

Public repository tree, primary HTML routes, Python entry points, policy files, sitemaps, documentation, attached `arcana-suite.zip`, production landing page, and all three Stripe Payment Links currently found in production content.

## Confirmed critical/high findings

1. **Checkout/product mismatch:** the $99/year CredentialAuditor checkout was also labeled as $15/month, $39/month, $49/month, $99/month, $299/year, and $790/year ARCANA plans.
2. **Paid download exposure:** documentation and store content linked paid ZIP artifacts directly before payment. Paid delivery needs authenticated or Stripe-managed fulfillment.
3. **Broken navigation:** several pages contain malformed nested attributes such as `href="href="index.html""`.
4. **Duplicate case-variant routes:** `Store.html`/`store.html`, `Free.html`/`free.html`, `Pro.html`/`pro.html`, and `Success.html`/`success.html` can diverge and behave differently on case-sensitive hosting.
5. **Placeholder security policy:** the prior `SECURITY.md` described fictional version lines and contained template instructions.
6. **Misleading/unsubstantiated marketing:** repository star/fork counts and “court-ready/court-admissible” claims are stated without qualification or evidence. Legal admissibility depends on process, jurisdiction, examiner, validation, and evidence handling.
7. **Repository contamination in `arcana-suite`:** Git internals (`HEAD`, `config`, `hooks/`, `index`, `info/`) and duplicated project roots were committed as ordinary source files.
8. **Stale canonical destinations:** docs pointed to a GitHub Pages project instead of `arcana-forensics.com`.
9. **Incomplete discovery:** sitemap omitted products, PASTE TRAP, and media pages.
10. **Third-party font request:** PASTE TRAP imports Google Fonts, conflicting with broad “offline/no cloud dependency” messaging on that route.

## Implemented on this branch

- Rebuilt the landing page around verified products and destinations.
- Rebuilt the product page with three checkout/product/price matches.
- Added canonical, Open Graph, and structured organization metadata.
- Refreshed README, link registry, security policy, and sitemap.
- Removed unverified ARCANA tier buttons from the audited product page.
- Added `rel="noopener noreferrer"` to external new-tab links.
